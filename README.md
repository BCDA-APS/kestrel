## Usage

Kestrel runs as a service at the APS; there is nothing to install. See the
[user guide](https://bcda-aps.github.io/kestrel/) for the address and a walkthrough.

In short: enter your Tiled server URL, click **Connect**, select a catalog, and
click a run to plot it.
